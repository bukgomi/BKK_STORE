### PG·간편결제 심사에서 공통으로 보는 것

- [ ] 사이트 하단(footer)에 **상호 · 대표자명 · 사업자등록번호 · 소재지 · 통신판매업신고번호 · 전화 · 이메일** 표기. 사업자등록증과 글자 하나까지 일치
- [ ] 통신판매업 신고 완료 (공정위 사이트에서 조회 가능해야 함). 기존 카페24 사이트로 신고했던 것이면 **도메인·상호가 바뀌는 경우 변경신고** 필요

- [ ] 청약철회(환불·교환) 안내 페이지
- [ ] 실제 상품 **3개 이상** 등록, 가격 표시, 장바구니→결제창까지 동작

## 1. 네이버 로그인

**어디서:** https://developers.naver.com → 로그인 → `Application` → `애플리케이션 등록`

### 절차

1. **애플리케이션 이름**: 쇼핑몰 이름 (40자 이내, 사용자에게 동의창에 표시됨)
2. **사용 API**: `네이버 로그인` 선택
3. **제공 정보 선택** (회원가입에 쓸 것만)
   - 필수: 이메일, 이름
   - 추가(선택): 휴대전화번호, 생일, 성별 — 필요 없으면 빼는 게 검수에 유리
4. **로그인 오픈 API 서비스 환경**: `PC웹` 추가
   - 서비스 URL: `https://<도메인>`
   - **Callback URL**: `https://<도메인>/api/auth/callback/naver`
     (NextAuth 기본 경로. 실제 경로는 Claude Code에서 `src/app/api/auth` 확인)
   - 로컬 테스트용으로 `http://localhost:3000/api/auth/callback/naver`도 함께 등록 가능
5. 등록 완료 → **Client ID / Client Secret** 표시됨
6. `.env.production`에 넣기: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` (변수명은 `.env.example` 기준)

### 검수

- 등록 직후엔 **"개발 중" 상태**. 등록자 본인과 `멤버관리`에 추가한 테스터 계정만 로그인 가능
- 일반 사용자가 쓰려면 `검수 요청` 필요. 서비스 URL 접속 가능 + 개인정보처리방침에 네이버 제공 정보 처리 명시가 요구됨
- 검수는 보통 며칠. 사이트 배포 후 신청

## 2. 카카오 로그인

**어디서:** https://developers.kakao.com → `내 애플리케이션` → `애플리케이션 추가하기`

### 절차

1. **앱 만들기**: 앱 이름, 회사명, 카테고리(쇼핑)
2. **앱 아이콘 등록** (비즈 앱 전환 조건이므로 먼저 해둘 것)
3. **플랫폼 등록**: `앱 설정 → 플랫폼 → Web` → 사이트 도메인 `https://<도메인>` (경로 없이 도메인만)
4. **카카오 로그인 활성화**: `제품 설정 → 카카오 로그인` → 활성화 ON
   - **Redirect URI**: `https://<도메인>/api/auth/callback/kakao`
   - 로컬용 `http://localhost:3000/api/auth/callback/kakao`도 추가 가능
5. **동의항목** 설정: `카카오 로그인 → 동의항목`
   - 닉네임, 프로필 사진: 기본 제공
   - **이메일을 "필수 동의"로 하려면 비즈 앱 전환 필수** (아니면 "선택 동의"만 가능 → 이메일 없이 가입하는 회원이 생김)
   - 전화번호: 비즈 앱 + 별도 권한 신청
6. **비즈 앱 전환**: `앱 설정 → 비즈니스` → 사업자등록번호 입력 → 심사(보통 당일~1일). 앱 오너 계정만 가능
7. **키 발급**: `앱 설정 → 앱 키` → **REST API 키** 복사
8. **Client Secret**: `카카오 로그인 → 보안` → 코드 생성 → 활성화 `사용함`
9. `.env.production`: `KAKAO_CLIENT_ID`(=REST API 키), `KAKAO_CLIENT_SECRET`

### 검수

- 카카오 로그인 자체는 별도 검수 없음. 비즈 앱 전환만 되면 바로 일반 사용자 가능
- 전화번호·배송지 같은 민감 항목만 개별 권한 신청

## 3. 토스페이먼츠

코드베이스 연동: 결제위젯/표준결제 (`TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`)

**어디서:** https://www.tosspayments.com → 회원가입 → 개발자센터

### 절차

1. **회원가입 즉시 테스트 키 발급**: `개발자센터 → API 키` 에서 테스트 클라이언트 키·시크릿 키 확인 → 개발·테스트는 계약 전에 끝낼 수 있음
2. **계약 신청**: `내 상점 → 계약 신청` → 사업자 인증(사업자등록번호) → 사이트 URL, 취급 상품, 예상 매출 입력
3. **서류 제출**: 공통 서류 업로드
4. **담당자 안내**: 약 3영업일 내 계약 조건(수수료·보증보험 여부) 안내 → 전자계약
5. **카드사 심사**: 계약 후 카드사별 심사 **약 2주**. 이 기간엔 실결제 불가
6. **라이브 키 발급**: 심사 완료 후 `API 키`에서 라이브 키 확인 → `.env.production` 교체

### 비용

- 등록비·연회비: 없음이 기본
- 수수료: 카드 매출등급(영세/중소/일반)별 차등, 계약 시 확정. 계좌이체·가상계좌 별도
- 보증보험: 예상 매출·결제수단에 따라 요구될 수 있음

### 사이트 심사 포인트

- 0번 체크리스트 전부 + 결제창까지 실제 동작
- 심사 중엔 테스트 키로 결제 플로우가 보여야 함

## 4. KG이니시스

코드베이스 연동: INIStdPay (`INICIS_MID`, `INICIS_SIGN_KEY`)

**어디서:** https://www.inicis.com → 서비스 신청. 또는 대리점(호스팅사·결제대행 리셀러) 경유

### 절차

1. **신청** → **가계약**
2. **바로오픈**: 당일 테스트 MID + 키파일 발송 → 개발 시작
3. **사이트 심사**: 0번 체크리스트
4. **전자계약** → **본계약** (신청 후 **30일 이내** 완료해야 함, 넘기면 재신청)
5. **카드사 심사**: 통상 7~10일
6. 운영 MID·사인키 발급 → `.env.production`

### 비용

- **초기등록비 0~30만원, 연관리비 0~30만원** — 직접 신청 vs 대리점에 따라 크게 다름. 대리점(코드엠샵, sir.kr 등) 경유 시 면제되는 경우가 많음. **신청 전에 반드시 견적 비교**
- 수수료(참고, VAT 별도): 카드 영세 ~1.8% / 일반 ~2.8%, 계좌이체 ~1.8%, 가상계좌 건당 ~300원, 현금영수증·에스크로 무료
- 간편결제(네이버페이·카카오페이·삼성페이·토스페이 등)를 이니시스 결제창 안에 포함 가능 → 별도 가맹 불필요

### 연락처

- 신규계약: 02-3430-5858 / 기술: 02-3430-5960

## 5. 네이버페이 (결제형)

코드베이스 연동: NaverPay v2 직가맹 API (`NAVERPAY_CLIENT_ID`, `NAVERPAY_CLIENT_SECRET`, `NAVERPAY_CHAIN_ID`)

**어디서:** https://admin.pay.naver.com → 가맹점 가입 → `결제형`

### 가입 조건 (이게 제일 까다롭다)

- **운영 1개월 이상 + 거래 실적** → 오픈 직후 신청 불가
- 사이트 하단 사업자 정보 5종(상호·사업자번호·대표자·소재지·통신판매번호)이 등록증과 완전 일치
- 통신판매업 신고가 공정위에서 조회돼야 함
- **다른 PG를 통해 네이버페이를 이미 제공 중이면 불가** → 기존 카페24 사이트에서 네이버페이 쓰고 있었다면 같은 사업자번호로 중복이 되므로 기존 것 해지 후 신청
- 배송·서비스 제공 기간 12개월 초과 상품 불가
- 취소는 원결제수단으로만

### 절차

1. 가입 신청 → 조건 확인 → 서류 심사 → 고객확인(AML) : **최대 1주**
2. 서류: 사업자등록증(1년 이내), **최근 6개월 평균 거래 증빙 또는 전월 매출 자료**, 법인은 등기부등본(3개월)·주주명부
3. 보증보험 가입 (거래 규모별 금액 안내됨)
4. 승인 후 개발자센터에서 Client ID/Secret/Chain ID 발급 → `.env.production`

### 주문형 vs 결제형

- **결제형**(코드베이스가 쓰는 것): 우리 사이트에서 주문하고 결제만 네이버페이. 회원·주문 데이터가 우리 DB에 남음 → 포인트 정책과 맞음
- 주문형: 네이버가 주문·배송·CS까지 가져감. 스마트스토어에 가까움. 이번 사이트엔 맞지 않음

### 우회 옵션

급하면 토스/이니시스 결제창 안의 "네이버페이" 간편결제로 먼저 열 수 있다. 직가맹보다 수수료·적립 조건이 다르고, 코드 연동도 PG 쪽 결제창을 쓰는 방식이라 현재 NaverPay v2 코드와는 별개다.

## 6. 카카오페이

**현재 코드베이스에 카카오페이 연동 없음.** 붙이는 방법은 둘.

### (a) PG 결제창에 포함 — 추천

- 토스 또는 이니시스 계약 시 "간편결제: 카카오페이 포함"으로 신청
- 별도 가맹 신청·개발 없음. PG 결제창에서 카카오페이 버튼이 뜸
- 수수료는 PG 계약 조건 따름

### (b) 직가맹 (partner.kakaopay.com)

- 기간 2~4주. 1차 신청(5영업일 심사) → 2차 신청(서류) → 연동
- 조건: 사업자등록, **자체 구축 사이트에 직접 API 연동** (카페24·아임웹 같은 호스팅형은 별도 경로), 상품 3개 이상, 약관·취소 규정 게시
- 비용: 등록비 22만원(현재 면제), 연회비 없음, 수수료 0.9~3.2% (연매출 구간별)
- 개발 필요: 결제 준비/승인/취소 API 연동 + 관리자 정산 화면. 작업지시서로 별도 발주해야 함

→ 처음엔 (a)로 열고, 카카오페이 비중이 커지면 (b) 검토.

## 7. 추천 진행 순서

| 시점 | 할 일 |
|---|---|
| **지금** | 네이버·카카오 로그인 앱 등록, 카카오 비즈앱 전환, 서류 스캔본 준비 |
| **지금** | 토스페이먼츠 가입 → 테스트 키로 결제 개발 마무리 |
| **서버 배포 직후** | 사이트 하단 정보·약관·상품 3개 확인 → 토스 계약 신청 + 네이버 로그인 검수 요청 |
| **계약 후 ~2주** | 카드사 심사 대기 → 라이브 키 교체 → 실결제 1건 테스트 |
| **오픈** | 토스(카드·계좌이체·카카오페이 포함)로 영업 시작 |
| **오픈 +1개월** | 네이버페이 결제형 신청 (거래 실적 첨부) |
| **선택** | 이니시스는 토스 조건이 안 맞거나 2차 PG가 필요할 때 |

PG를 처음부터 둘 다 열 필요는 없다. 코드는 둘 다 준비돼 있으니 하나로 시작하고 나중에 추가하면 된다.
